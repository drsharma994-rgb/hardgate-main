1. MEASUREMENT SCRIPTS (3 files)
─────────────────────────────────

  ✓ scripts/crypto-fill-risk-cal.mjs (12KB)
    Main replay script — OMNIROUTE-integrated measurement
    - Fetches 1,000 bars per horizon from Binance FAPI
    - Runs hgOmniDetect on each bar prefix
    - For each firing: records entry, stop, livePx, gap in R
    - Walks forward: checks if entry fills within horizon
    - Buckets results: [0–0.25R], [0.25–0.5R], [0.5–1R], [1R+]
    - Outputs: % never-filled for each bucket, both horizons
    - Runtime: ~20–40 minutes
    - Output: scripts/crypto-fill-risk-results.json
    - Status: ✓ Syntax verified, ready to run

  ✓ scripts/crypto-fill-risk-direct.mjs (8.6KB)
    Simplified measurement — doesn't require detector firing
    - Simulates limit orders at gaps: 0.1R, 0.25R, 0.5R, 1.0R, 1.5R
    - Places order at each distance below market (long only)
    - Walks forward to measure if order fills within horizon
    - Faster execution (~5–15 minutes)
    - Output: scripts/crypto-fill-risk-direct-results.json
    - Good for quick validation or when detectors are sparse
    - Status: ✓ Syntax verified, ready to run

  ✓ scripts/test-crypto-fill-risk.mjs (8.1KB)
    Test harness with mock data (development only)
    - Generates synthetic OHLCV bars
    - Runs same logic as main replay without network calls
    - Validates measurement logic without depending on Binance
    - Runtime: <10 seconds
    - Status: ✓ Syntax verified, runs successfully
