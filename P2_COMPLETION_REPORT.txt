================================================================================
                            KEY FEATURES
================================================================================

1. LIQUIDATION INTEGRATION (P2 Pillar #8)
   • Projects liq map from recent price extremes at 10x/25x/50x/100x leverage
   • Direction-aware: only considers relevant liq clusters
   • Scoring: 12pts for 0.25-0.5x ATR (sweet spot), 8pts for 0.5-1x, 4pts for 1-2x, 0pts beyond
   • Bonus: +2pts if stop positioned away from major liq
   • Graceful: returns 0pts with explanation if liq map unavailable (not a veto)

2. EXPECTANCY SCORING (P2 Pillar #9)
   • Scores measured expectancy: 8pts (≥+0.50R), 6pts (≥+0.25R), 3pts (≥0R), 0pts (<0R)
   • Scores sample size: 8pts (≥50), 6pts (20-49), 3pts (10-19), 1pt (<10)
   • Returns: max of both scores (whichever is higher)
   • Default: 3pts (neutral) if no historical data available
   • Transparent: reports both components + hit rate

3. SOLIDITY TIER MAPPING
   • 85-100: Extremely Solid (all pillars aligned)
   • 70-84: Solid (most aligned, <2 weak)
   • 55-69: Fair (mixed, 3-4 weak, requires premium R:R)
   • <55: Weak (too many conflicts, avoid unless exceptional edge)

4. 100-POINT SCALE
