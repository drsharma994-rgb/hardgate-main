P3 IMPLEMENTATION SUMMARY
================================================================================

Three research-backed, logically-distinct indicators added:

1. ORDER FLOW CONFLUENCE (12 pts)
   ├─ Detects order flow imbalance alignment with entry direction
   ├─ Scores: 12pts (+2σ aligned) → 10pts (+1σ) → 5pts (±0.5σ) → 0pts (counterflow)
   ├─ Bonus: +3pts if sustained >5 bars (capped at 12)
   ├─ Default: 0pts if no order flow data (never vetoes)
   └─ Edge: True edge many traders miss; directly measurable from broker/onchain

2. STRUCTURAL SUPPORT/RESISTANCE CONFLUENCE (15 pts)
   ├─ Entry proximity to multi-touch structural levels (swings, round #s)
   ├─ Scores: 15pts (2+ within 0.25x ATR) → 10pts (1 @ 0.25x or 2+ @ 0.5x)
   │         → 5pts (1 @ 0.5x or 2+ @ 1x) → 0pts (no proximity)
   ├─ Bonus: +3pts if stop on structural level (capped at 15)
   ├─ Detects: Swing highs/lows, round numbers, VWAP (extensible)
   └─ Foundation: Wyckoff-level thinking; universally applicable

3. MOMENTUM CONVERGENCE (12 pts)
   ├─ Alignment of RSI(14), MACD(12,26,9), Stochastic(14)
   ├─ Scores: 12pts (all 3 agree) → 8pts (2/3) → 4pts (1/3) → 0pts (none/disagree)
   ├─ Thresholds: RSI >50 (bullish), MACD >0 (bullish), Stoch >50 (bullish)
   ├─ Default: 0pts if <30 bars or indicators unavailable (never vetoes)
   └─ Layer: Technical confirmation without overweighting technicals

Total P3: 12 + 15 + 12 = 39 pts (as recommended)
